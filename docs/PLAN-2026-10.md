# Sol — Audit Remediation Plan (2026-10-04 audit, 31 findings)

## Context

The 2026-10-04 audit (https://claude.ai/artifact/9HqnRTiJKcuBnZvuALvs8s) found the live site
reporting `ok` while showing guests old or missing imagery, an app that can hang or crash on a
phone with no message, a validator that can block every product over one bad number, and an
operator loop that depends on someone noticing a noisy GitHub issue. The user selected 31 of 32
findings. **#2, the Cloudflare Worker relay, was left out**, so the laptop GONG mirror stays the
only relay. This plan therefore makes mirror outages *shorter* (auto catch-up) and *honest*
(T3 and quieter alerts). It does not make them rarer.

Decisions already taken:
- **Alerts (#6):** GitHub only, made quieter and smarter. No external service.
- **HMI (#1):** guard immediately, then add a current HMI source. Exploration found it:
  **JSOC's dated tree** `https://jsoc1.stanford.edu/data/hmi/images/YYYY/MM/DD/YYYYMMDD_HHMMSS_{Ic,Ic_flat,M}_4k.jpg`,
  current to ~20 min, 15 min cadence, obs time in the filename, 4096 px greyscale. The disk fills
  **0.929** of the frame, not SDO's 0.9184, and orientation is unverified. Helioviewer lags ~4 h
  and would need JP2 decoding, so it is not used.
- **Alex's features (#31):** T15 (zoom-out + own orbits), T13 (tap-to-explain) and T14
  (press-and-hold scrub) get built. T16 / T17 / T9 get scoping and decisions only.

Outcome: nothing a guest sees is older than it says it is. A stalled or crashed 3D view always
explains itself. One bad record or upstream move degrades one product loudly instead of all of
them quietly. The docs a session loads are short and true.
