# Design audit working files

Rescued from a session scratchpad, which is not durable. These belong to the
in-progress visual-design audit — see `HANDOFF.md` §8, which is the actual
handoff document; this directory is just the artifacts that section refers to.

- `Palette.dc.html` — the one finished design-canvas artboard (the palette
  proposal). The remaining artboards were never built; §8.5 lists them.
- `cr.py` — WCAG contrast-ratio calculator used to settle the palette. The
  measured table it produced is in §8.3, so this only needs re-running if the
  candidate colours change.

Nothing here is loaded by the app or the pipeline.
